# Spring AI Playground

> A sample project demonstrating how to build AI-powered applications using Spring AI and Spring Boot.

## 🚀 Overview

This repository provides examples and experiments using **Spring AI** to integrate Large Language Models (LLMs) into Spring Boot applications.  
It showcases common AI use cases such as chat, prompt templates, embeddings, and retrieval-augmented generation (RAG).

The goal of this project is to serve as:
- A learning resource for Spring developers
- A reference implementation for Spring AI features
- A starting point for building AI-enabled Java services

---

## ✨ Features

- Spring Boot–based setup
- LLM chat and text generation
- Prompt templates
- Embeddings and vector search
- Retrieval-Augmented Generation (RAG)
- Tool / function calling (where supported)
- Configurable AI providers

---

## 🧰 Tech Stack

- Java 17+
- Spring Boot
- Spring AI
- Maven / Gradle
- Supported AI providers:
  - OpenAI
  - Azure OpenAI
  - Anthropic
  - Local models (e.g. Ollama)
